# Where stewardship belongs

`cto-legends` discovers and prepares capabilities. `legends-empire` holds
durable knowledge and operating records. Stewardship maintains their quality.
Other modules add specific capabilities. This is a relationship, not a demand
that every vault adopt identical folder names.

This pack is **machinery**: reusable methods and record contracts. Its default
home is `wiki/library/legends-empire/stewardship`. The user can choose another
supported `wiki/library/` location when attaching it. The public Empire package
does not claim to install the founder's entire personal vault structure.

| Kind of information | Appropriate home |
| --- | --- |
| Reusable methods and templates | This pack's versioned references |
| The user's maintenance goal, scope and findings | A maintenance campaign in the user's work space |
| Project outcome, owner, evidence and next action | The canonical project record |
| Session objective, established facts and resume point | A session handoff linked from the project |
| Chosen direction and its reason | A decision note linked to the affected work |
| Evidence of a completed operation | A receipt linked from its campaign or project |
| A captured idea without a settled home | The user's inbox until reviewed |
| Code, builds, credentials and large assets | Their source system, with appropriate references from the vault |

Prefer one canonical record plus links. Do not duplicate a project into this
pack merely to track its maintenance. Add a useful route from the user's
existing index when authorized. Pack attachment does not rewrite that index.

An orphan can be an intentional receipt or private working note. Stale can
mean stable, paused or waiting. Folder location and timestamps are clues.
Read the record and its context before classifying a problem or moving content.

Module updates own shipped references only while those references remain
unchanged. User-edited references produce a conflict for review. Local work
and the attachment entry point remain user owned. Removed upstream references
are retained as obsolete until a person or agent reviews their relationships.
